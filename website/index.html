Render them yourself

You need Python 3.11 or newer and ffmpeg. The first render of a network animation downloads MNIST (or GPT-2) and trains the model, which is cached afterwards.

git clone https://github.com/{{repo}}
cd voxanim
python3 -m pip install -r requirements-lock.txt
python3 -m voxanim render gradient-descent

The same commit renders the same pixels: the fonts are bundled, downloads are checked against fixed checksums, and each render writes a manifest with the SHA-256 of every file. The README explains how each animation is built.

voxanim {{version}}, released under the MIT licence. The conv2d animations follow the originals by Animated AI. The grid plays the first half of each animation small; point at a clip for the sharper preview, click it for the full 960×540 file.
